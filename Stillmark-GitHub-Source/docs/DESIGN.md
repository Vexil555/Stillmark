# 刻度 · 设计与架构

## 产品取舍

Forest 将留在专注状态与种树结果关联。刻度把承诺落在明确的动作上，先选择沉浸，再按下开始键，最后用结果记录回顾节奏。[Forest](https://www.forestapp.cc/)

Marinara Timer 将固定番茄、可调周期和普通计时分成不同入口。刻度在同一表盘保留深度专注和番茄钟两个档位，短休、长休和每组轮数放进设置，方便下一次沿用。[Marinara Timer](https://www.marinaratimer.com/)

锁定启用后，副屏只显示倒计时和阶段，主屏保留一个低对比度的提前结束入口。番茄休息自动开始，下一次专注需要主动确认。热力图按日看规律，时段柱图按实际占用时间累计，最近记录保留提前结束和熔断状态。

## 仪表视觉与声学

界面从一张 ImageGen 概念板发展而来。设计提示覆盖暖白外壳、侧栏与精密表盘、炭黑锁定和热力图及 24 小时分布。界面用代码绘制，刻度、指针和计时读数随实际状态更新。

标题与正文使用 Windows 本地中文 UI 字体。表盘使用随包携带的 Barlow Condensed，图表坐标、验证码及精确单位使用 IBM Plex Mono。表盘有 60 道刻线，每 5 道加重，橙红指针从 12 点位置按完成比例旋转。步进器、开关和开始键以约 200–270 ms 的自定义缓动回弹，沉浸界面以较慢的亮度过渡降低切换冲击。

按键声由短三角波和低频正弦尾音叠加，进入专注和休息使用不同的双音包络。长背景声由棕噪声、低通滤波和轻微低频谐振合成，音量可调。程序不需要下载或解码音频文件。

## 运行时

PySide6 提供 Windows 进程与窗口，Qt WebEngine 加载打包在应用内部的 React/TypeScript 资源。内部地址仅用于访问随包分发的页面、脚本、样式和字体。QWebChannel 将窗口命令和计时状态在界面与桌面进程间传递，计时、提前退出和持久化以原生进程为准。

计时用单调时钟的截止时刻计算剩余秒数，在 SQLite 中按 5 秒检查点保存有效专注。记录在完成或退出时定稿。当操作系统或应用异常退出，下次启动会将未结算记录标记为意外中断，锁定须重新由用户发起。

Windows 键盘钩子在独立进程的消息循环中运行，Qt 通过系统事件控制启停与心跳。每块显示器由单独的全屏窗口覆盖。熔断或心跳超时先摘除键盘钩子，主窗口随后解除覆盖。主进程确实无响应时，守护进程退出所属应用。这个设计使用当前 Windows 交互桌面的置顶与输入拦截能力，系统安全桌面由 Windows 管理。[LowLevelKeyboardProc](https://learn.microsoft.com/windows/win32/winmsg/lowlevelkeyboardproc)

## 实机核对

在 Windows 10 22H2 x64 运行便携版，用窗口内置 Chromium 的调试协议获取 1240 × 790 逻辑像素的截图。逐项对照 `CONCEPT.png` 中的双栏构图、60 道刻线与指针、窄体数字、暖白与炭黑配色、按钮和开关的明暗层次、主窗口文案。概念板的演示日期和统计值换成实时本地数据，统计与设置各有独立页面，沉浸锁定直接占满显示器。

实机走通主题切换、沉浸启动、错误输入重置校验码、键盘熔断及历史记录写入。实机环境连接一块屏幕，多屏覆盖与热插拔仍需在相应环境验收。
